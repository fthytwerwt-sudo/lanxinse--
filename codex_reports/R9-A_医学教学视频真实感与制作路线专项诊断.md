## 3. 画面到底变了多少

**同机位肉眼可见的变化。** R8-B 环绕中央开口的两侧括约肌形成更明确的深红轮廓，R7 较大的白色开口缩小。耻骨联合和关节的颜色更易区分。中央扇形肌面的纹理在 R8-B 更柔和、转向更清楚。大块肌面的轮廓、左右宽浅色附着边与骨盆框架仍高度相近。近收缩峰值也能看到本地形变的变化，旧验收中两侧跟踪区域平均上移由约 15.21 增到 18.33 像素（320 像素宽，无箭头）。这项读数衡量动作可辨识度。

**新增层在哪里能看到。** 按存档的 171 个姿态部件掩码统计，在 720×1280 底板的共同解剖区（行 200–1056，避开渐隐边）内，R8-B 有 31 个部件至少露出部分像素。静息全幅掩码为 33 个，另两项只露在统计区之外。恢复的 15 项在共同解剖区域中合计占 **1.87%–1.95%** 的轮廓内像素，静息时其中 **9,818 像素**来自双侧括约肌，其余只零星露出。两版静息整体轮廓的交并比约 **98.07%**。这些数据描述固定机位中实际可见的变化。在另一个下视静态中，已有显隐记录表明隐藏会阴膜能露出 4,283 个原先被遮挡的肛提肌像素。因此在审图位能观察到的真实分层改变，在成片镜头里大部分并未展开。

**与 CEO 对标的差异。** 在 `00:55.733` 的前上观察中，可见肌肉转向处的曲面起伏、从细到粗的纤维和肌肉到腱性组织的过渡。录屏还展示了从浅层盖住深层到隐藏浅层的关系。R8-B 保留大面积相邻的平滑肌面，浅色边缘显得较齐，骨面与肌面在局部交界处过渡较硬。两种表现从编码前就有差距。用户认可的 ChatGPT 原图尚未定位，对它的逐像素差异和采用的制作方式保留待验证。

## 4. 原始模型、灯光和 480P 的分量

**原始模型有当前资产的细节上限。** R8-B 使用的文件中，单侧髂尾肌为 **2,993 顶点／6,746 三角面**，单侧耻骨直肠肌为 **825／1,698**，单侧会阴膜为 **617／1,102**。网格三角边长的中位数约 1.7 mm（项目坐标），这些读数用于描述资产。观察到的限制主要在于大肌束包络连续且较平、附着和连接区简化、没有逐束表面高度、以及源分组未把某些组织细分。补贴图或改灯能强化已有起伏和材质，改变真实截面厚度、明确附着面和补出可显隐的组织仍需几何数据。发布者将该工具用于教学、研究与交互式可视化。现有网格能否借专业材质达到用户的视觉档次还需实测。[原始资产发布与许可](https://zenodo.org/records/17421995)

| 取证试验 | 控制与唯一改动 | 结果与限度 |
|---|---|---|
| 同帧底板复现 | 实际 43 件 NPZ 与相同显隐、相机、静息姿态，原代码运行。 | 720×1280 底板逐像素一致，部件 ID 零差。固定此条件再做下面两项。 |
| 仅材质 | 只把程序纤维的颜色起伏乘 1.65。保持几何、粗糙度、阴影、相机不变。 | 纤维看起来更清楚，部分区域的条纹感也更强。肌束轮廓、厚薄和连接处没有变化。279,407 个可见肌肉像素内的 8 位通道平均绝对变化为 1.75。 |
| 仅灯光 | 材质、镜头、网格相同，只把主光移至更侧向的角度及随之变化的阴影投影。 | 肌面明暗和局部包覆感变化最大，同区平均绝对变化为 7.61。宽浅色边与大肌面的接缝关系未改善，个别骨缘暴露阴影锯齿。E 保留这一张作为观察现有渲染能力的样本。 |

现有渲染器已做 470×470 光源深度图采样及按屏幕邻域近似的遮蔽。其软组织材质缺少受纤维方向影响的反射、组织边界的法线或位移细节以及次表面散射。Blender Cycles 支持路径追踪和基于物理的材质，Principled 材质可给不同组织独立处理粗糙度、法线和次表面散射。贴图、灯光和网格仍需设置，薄面、开口或重叠网格要验证散射效果。本机常用入口未发现 Blender，本轮未安装或运行。当前结论关于现有渲染和可验证的能力差异，专业渲染的成图尚待验证。[Blender 渲染官方说明](https://www.blender.org/features/rendering/) · [Principled BSDF 官方说明](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html)

## 5. 归因和执行偏差

| 因素 | 判定 | 证据与责任层级 |
|---|---|---|
| 原始模型细节 | **部分成立** | 原始网格与现有组织分组限制真实厚度、细致附着及筋膜相接的表现。现有资产在更好着色下的视觉上限仍待验证。属于资产和路线选择。 |
| 阿里模型 | **已排除** | 本轮待诊断的 R8-B 所用几何、底板、编码及最终哈希形成可回读链条。付费生成 0 次。 |
| 生成 Prompt | **已排除** | R8-B 没有生成模型输入。不存在扩写 Prompt 后改变画面的问题。 |
| 制作任务的视觉要求 | **部分成立** | R8-B 执行单明确写了厚度、纹理、组织层叠和既有风格。CEO 原视频用于结构和可见性参考，代码和记录未见已认可的 ChatGPT 原图成为有版本、同裁切的视觉验收输入。在任务图示到具体材质、几何及验收样本的传递上有缺口。ChatGPT 原图的具体出处仍待验证。 |
| 材质和渲染 | **已确认** | 控制变量试验显示颜色和主光会明显改变纤维感和可读的体积。真实纤维体积和跨组织连接需要几何与材质共同表达。现有实现的物理材质能力决定了可呈现的细节。 |
| 执行与验收偏差 | **已确认** | 恢复 43 个部件、按肌群分纤维走向、保持原稿与动作清晰度均落实。任务写明的“肌肉具有明显改善的立体质感”没有经参照图与无字同机位静帧验收，已有记录主要检查结构、位移、纹理可读与技术播放。用户对 R8-B 真实感的反馈表明这项视觉目标未达。解剖正确性仍待医学人员审查。 |
| 480P 导出 | **部分成立** | 清晰度和色度有轻微差值。源图已有同样的轮廓、接缝和肌面问题。样本覆盖静息和近峰值两帧。 |

**R8-B 的质感缺少独立验收。** R8-B 以“能载入、能显隐、能稳定运动”证明结构工作有效。观众看到的却是同机位下几乎相同的大肌面，仍以程序纹理和简化光照承担组织质感。制作过程中缺少在成片镜头中、去掉教学叠加后，与目标质感做静态对照的执行证据。恢复部件和材质规则的工作确实做过，真实感仍待单独过关。

## 6. 路线重判和唯一下一项验证

| 路线 | 判断 |
|---|---|
| A · **主路线**，保留 WBU v2 结构，升级材质和渲染 | 保留目前已验证的坐标、可显隐能力和动作入口。以能控制分组织法线、材质和面积灯的专业渲染器对同一网格做静态验证。现有 MIT 资产无需新增许可费。Blender Cycles 是可验证候选，接入工时和设备渲染时间待测。 |
| B · **备选**，替换经过确认的局部几何 | 如果同网格在更好渲染后，仍是轮廓、厚度、附着和组织分层先失真，再针对可见肌群换有独立分层、可编辑、明确授权的高精度网格，或由医学建模人员局部补建。现有骨盆坐标作为参照。资产成本与再绑定时间待核。 |
| C · 图像生成底图再动画 | 可用于风格探索。要成为制作主路线，仍缺同结构多状态一致性、分层边界和运动保持的证据。当前不采用。 |
| D · 更换视频生成模型 | 本片没有视频生成环节，对该路线没有直接归因证据。当前不采用。 |

**下一轮只做一次同网格的专业静帧对照。** 用 R8-B 的 `00:00.000` 放松姿态、同角度、同显隐与同裁切，复用这次已复现的底板作基准。待复审确认后只在渲染一侧升级分组织材质和软光，交一张无字无箭头的前后对照，兼看原尺寸及 480 宽。与 CEO 对标 `00:55.733` 同看，按纤维、体积和组织交接分别判断。若能定位用户认可的 ChatGPT 原图，把它放在旁边作为质感目标。过于平整的曲面或生硬附着若在升级后仍占主导，转入 B 的单一重点组织验证。先交用户、CEO 核对质感，专业人员核对结构，复审之后才决定是否做动画。

本轮归档在已核验的本地项目根。只写两份诊断成果及隔离的静态测试记录。未改前版成片、教学原稿、生产代码或项目治理，未生成新版视频、未调用付费模型、未上传。视频探针的完整解码结果仅作技术验证。
